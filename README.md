# 杨周鑫 · 求大佬组队

像素 2D 星露谷风格的个人介绍页。点击四间小屋的门，小人会走过去开门进屋，弹出对应内容：

| 小屋 | 内容 |
|---|---|
| 🔴 个人履历 | 姓名 / 年龄 / 身份 / 工具链 / 擅长 |
| 🔵 基本介绍 | 称呼 / 年龄 / 身份 / 性格 / 状态 |
| 🟠 性格特点 | 活泼开朗 / 能交际 / 虚心 / 细心 / 抗压 / 团队 |
| 🟢 能干什么 | 网页设计 / AI 工具流 / 快速出活 / Demo 展示 / 上台路演 / 补位 |

## 玩法

- 点小屋的**门** → 小人寻路走过去 → 开门进屋 → 弹出介绍
- 弹窗**右上角 ✕** 关闭（也可点遮罩或按 Esc）
- 键盘 `1` `2` `3` `4` 直达对应小屋
- 左上角可开关**背景音乐**和**音效**

## 技术

单文件 HTML，**零外部依赖** —— 美术、音乐、音效全部由代码实时生成：

- Canvas 像素渲染（256×192 逻辑分辨率整数放大 + nearest-neighbor）
- BFS 网格寻路 + 状态机（idle / walk / enter / inside / exit）
- Web Audio 实时合成 chiptune（132 BPM，C 大调 I–V–vi–IV，四声部）与 8 种音效

> 浏览器策略要求先点一下页面才会出声。
